# Roadmap

1. Evaluate real recordings and user-owned music; inspect candidate quality and cut timing. Add visual preview and manual candidate/timeline corrections.
2. Separate pipeline modules and introduce cancellable background jobs/progress, resource limits and resumable analysis.
3. Improve beat/phrase analysis, game-adapter evidence and confidence labeling.
4. Build Windows desktop UI and installer with actual Windows execution tests.
5. Add sound-design mixing, transitions, speed ramps and validated GPU encoding.
6. Evaluate optional local vision/audio models and learned direction against curated, licensed test sets.

All items above are planned. No advanced montage/AI specification was present below the repository instructions in this session; further product requirements should be recorded before committing to model/UI architecture.
